# Comments replay adjudication plan

Frozen before launching the Comments runs on 2026-11-18. Each case gets a fresh `review-comments` task with `gpt-6.2-sol` and `high`. The synthetic cases use `snapshot,workspace` for the bounded handler and guide chain. The MCP reruns use `snapshot,workspace,web` for external client facts. Each reviewer sees a separately checked-out repository with a neutral name as its working directory. The evaluation files, prior reports and other cases live outside that directory. The endpoint range is explicit, and the caller keeps validation separate from the reviewer.

Assess each finding independently for factual support, role scope, severity, actionable wording and changed-source anchoring. A blocking documentation finding requires a contradiction with a required consumer path or a materially false promise whose documented use fails. A reasonable clarification of a caveat or a stylistic change is a suggestion. Score factual matches independently from severity. A report with no findings can pass a clean case. An incomplete report or tool error cannot establish a negative result. A changed-file anchor in the handler can legitimately point to a separate edit location in an unchanged guide.
