### Catalog 的独立证据

`README.md:30,48–55` 支持可独立编辑的部署配置和模板上游拣选。保留原配置的部署输入缺少新键时，浏览器配置回退清空组织并跳过初次加载，导出脚本在采集前退出。随新版本一并更新配置的普通检出含空数组，属于通过路径。发现应将条件写明。前端二次网络失败的[函数探针](probe-catalog-details.js)确认 base 保留组织模型，原版和诊断修复返回空列表，性能修复保留组织和外部模型。测试用本地响应和 DOM 查询替身，没有运行浏览器。

认证发现只基于源码、工作流、官方仓库 ID 校验和不依赖真实令牌的分支分析。没有执行真实认证请求。HTML 发现可证实代码拼接和新增加的数据来源；真实上游返回与浏览器影响没有独立实验。关于 HTML 的结论保留为条件性风险。[Hugging Face 详情类型](https://github.com/huggingface/huggingface.js/blob/main/packages/hub/src/types/api/api-model.ts) · [仓库 ID 校验源码](https://github.com/huggingface/huggingface_hub/blob/main/src/huggingface_hub/utils/_validators.py) · [模型卡说明](https://huggingface.co/docs/hub/model-cards)
